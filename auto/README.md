## Formula Slug Onboarding Auto Subsystem

## Project Overview

This project was completed as part of the Formula Slug software onboarding
process.

The project has two main parts:

1. **PID Controller:** Implemented a PID controller to control a 1-D simulated
   car and bring its velocity toward a desired velocity.

2. **Machine Learning Extension:** Used data generated by the PID controller
   to train a PyTorch linear regression model that predicts desired
   acceleration from the car's current velocity and desired velocity.

## How to Run

Navigate to the `auto` directory in the folder:

- cd auto
- run python3 run_template.py

The program will:
- Simulate the car using the PID controller
- Generate training and testing data
- Train the PyTorch model
- Evaluate the model
- Display the results and plots

## PID Results

The controller was tuned to reach a target velocity of 20 m/s.

- Desired velocity: 20 m/s
- Time step: 0.1 seconds
- Simulation steps: 550
- Simulation time: 55 seconds
- Final velocity: approximately 19.999 m/s
- K_P: 0.8
- K_I: 0.2
- K_D: 0.1
